# 찾았당

## 프로젝트 소개

찾았당은 면접·온라인 시험 안내문을 분석해 필요한 공간을 찾고 예약을 돕는 청년 생활자원 예약 서비스입니다.
안내문 캡처나 텍스트에서 일정과 준비물을 읽고, 지역·예산·보유 장비에 맞는 공간을 탐색합니다.

## 폴더 구조

```text
hckt/
├── frontend/
│   ├── src/
│   │   ├── pages/          시작·검색·예약·마이페이지
│   │   ├── App.tsx         화면 이동과 상태 관리
│   │   ├── api.ts          백엔드 API 통신
│   │   └── components.tsx  공통 UI
│   └── public/             이미지·아이콘·폰트
├── backend/src/
│   ├── main/java/kr/hckt/  인증·안내문 분석·검색·예약 처리
│   ├── main/resources/    서버 설정·DB 스키마·OCR
│   └── test/              백엔드 테스트
├── compose.yaml            PostgreSQL 구성
└── .env.example            환경변수 예시
```

## 주요 기능

- **안내문 분석**: 카메라 촬영·이미지 업로드·텍스트 입력으로 목적, 일정, 준비물을 추출합니다.
- **이용 조건 설정**: 지역 검색, 보유 장비·예산 설정, 날짜·시간 수정을 지원합니다.
- **공간 탐색**: 공유누리와 서울시 공공서비스예약에서 조건에 맞는 공간 후보를 찾습니다.
- **예약 승인**: 선택한 공간의 일정·금액·취소 조건을 확인하고, 지원하는 시설의 예약 절차를 진행합니다.
- **마이페이지**: 예약 내역과 진행 상태를 확인하고 계정 정보를 관리합니다.
- **공간·물품 카탈로그**: 전국 공공·민간 공간과 대여 물품을 담는 DB 구조를 제공합니다. 실제 데이터 수집과 API 연동은 준비 중입니다.
